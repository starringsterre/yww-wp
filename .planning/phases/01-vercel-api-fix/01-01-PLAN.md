<objective>
Pre-bundle the Express server into a single file for Vercel serverless deployment, remove the broken serverless-http wrapper, and pin the Node.js runtime.

Purpose: The API routes (Klaviyo form submissions) work locally but crash on Vercel because the serverless runtime cannot import files outside the api/ directory. Bundling server code into api/_server.mjs via esbuild solves this. This is the only blocker preventing the live site from processing form submissions.

Output: Working API endpoints on Vercel production -- all form submissions reach Klaviyo.
</objective>

  <files>package.json, api/[...all].ts, vercel.json, .gitignore</files>
  <action>
Four file changes, all serving one goal: make `api/[...all].ts` self-contained on Vercel.

**1. package.json** -- three changes:

a) Add `build:api` script that runs esbuild to bundle server/index.ts:
```
"build:api": "npx esbuild server/index.ts --bundle --platform=node --format=esm --packages=external --outfile=api/_server.mjs"
```

b) Update the `build` script to include the new step:
```
"build": "npm run build:client && npm run build:server && npm run build:api"
```

c) Add `engines` field at the top level (after `"type": "module"`):
```json
"engines": {
  "node": "22.x"
}
```

d) Remove `serverless-http` from devDependencies. Run `pnpm remove serverless-http` to remove it from both package.json and pnpm-lock.yaml.

**2. api/[...all].ts** -- complete rewrite (4 lines):
```typescript
import { createServer } from "./_server.mjs";

const app = createServer();
export default app;
```
This replaces the broken serverless-http wrapper. Vercel natively supports `export default app` for Express apps.

**3. vercel.json** -- remove the `functions` block entirely:
```json
"functions": {
  "api/[...all].ts": {
    "includeFiles": "server/**,shared/**"
  }
}
```
This block has no effect with the Vite framework preset and is no longer needed since the server code is now bundled into api/.

**4. .gitignore** -- add at the end, with a comment:
```
# Generated server bundle for Vercel
api/_server.mjs
```
This prevents the esbuild output from being committed (it is regenerated on every build).

After all changes, run:
1. `pnpm remove serverless-http` (updates package.json + lockfile)
2. `pnpm build` (must succeed, including the new build:api step)
3. Verify `api/_server.mjs` exists and exports `createServer` as a function
