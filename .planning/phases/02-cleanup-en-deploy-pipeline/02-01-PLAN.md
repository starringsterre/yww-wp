**1. Collect-errors pattern:**
Replace the current throw-on-failure approach. Add a `results` array and a `runStep()` wrapper function:

```javascript
const results = [];

async function runStep(n, total, label, fn) {
  step(n, total, label);
  try {
    await fn();
    results.push({ step: n, label, status: "pass" });
  } catch (err) {
    console.error(`  FAILED: ${err.message}`);
    results.push({ step: n, label, status: "FAIL", error: err.message });
  }
}
```

Wrap each of the 4 existing steps in `runStep()`. The existing `run()` helper still throws on non-zero exit (that's correct -- `runStep` catches it).
